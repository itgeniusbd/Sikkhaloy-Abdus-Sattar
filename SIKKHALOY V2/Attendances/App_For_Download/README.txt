Attendance device installer folder.

Place the latest SIKKHALOY_AttendanceDevice_Setup_x.x.xx.exe file here.
All .exe files in this folder are published to the live server.

The website Download Latest Version button and the desktop auto-update check
both use the highest version number in the file name
(e.g. SIKKHALOY_AttendanceDevice_Setup_4.0.79.exe).

Desktop apps call:
  https://sikkhaloy.com/Attendances/AttendanceDevice_Update.ashx
